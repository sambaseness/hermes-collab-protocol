How It Works

Four phases, never touching main

Phase 1

Initiation

Clone a repo with .hermes-collab.md. The skill auto-detects the protocol and bootstraps everything.

Phase 2

Task Assignment

Pull issues, view who has what, claim tasks matching your capabilities. Feature branches from develop.

Phase 3

Work Execution

Each device runs its agent (Hermes, OpenCode, Codex) on claimed tasks. PRs to develop require review.

Phase 4

Communication

State files, GitHub Issues, Discussions, Projects, and commit metadata keep everyone in sync.

The Protocol

One file, any repo. Branch policy: never touch main

1

Place .hermes-collab.md

Add the manifest to your repo root. Define your team, roles, and workflow.

2

Run project-collab.py init

Devices auto-detect the protocol. Creates develop branch and state file.

3

Agents Claim and Work

Devices pull issues, claim tasks, work on feature branches. PRs to develop.

4

Automate with Cron

Set up automatic sync every 30 minutes. Devices stay coordinated without manual effort.

Supported Agents

Hermes orchestrates, others execute

Orchestrator

Hermes

Full-stack coordination, lead tasks, complex workflows. Runs on all platforms.

Primary

OpenCode

Lightweight coding tasks, PR checks, tests, quick fixes. Free and open-source.

Parallel

Codex

Batch fixes, worktrees, parallel issue resolution. For heavy lifting.

Quick Start

Get going in seconds

$ curl -fsSL https://raw.githubusercontent.com/sambaseness/hermes-collab-protocol/main/installer.py | python3
$ cd your-repo && hermes init hermes-collab
$ project-collab.py pull
$ project-collab.py claim <number>
$ project-collab.py work
