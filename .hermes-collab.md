# Hermes Collab Protocol

This repo contains the Hermes Collab Protocol — enabling multi-device AI agent collaboration across teams.

## How Devices Bootstrapped

**No install script needed after initial setup.** The protocol is self-bootstrapping:

1. Clone any repo containing `.hermes-collab.md`
2. Hermes loads the `hermes-collab` skill automatically
3. Skill detects the manifest and activates collaboration protocol
4. Skill calls `project-collab.py bootstrap` to download the script
5. Device is ready to `claim`, `work`, `sync`

The `install.sh` is only for the very first device setup (before the skill is cached).

### Manual Setup (if needed)

```bash
# One-time setup on a brand new device
curl -fsSL https://raw.githubusercontent.com/sambaseness/hermes-collab-protocol/main/install.sh | bash

# Or just run bootstrap after cloning
cd your-repo && project-collab.py bootstrap
```

## Commands

```bash
project-collab.py init          # Initialize protocol in current repo
project-collab.py status        # Show team status and assignments
project-collab.py pull          # Fetch latest issues and state
project-collab.py claim <num>   # Claim an issue
project-collab.py work          # Start working on claimed tasks
project-collab.py sync          # Push state and PR updates
project-collab.py report        # Generate team progress report
project-collab.py bootstrap     # Download project-collab.py from GitHub
```
