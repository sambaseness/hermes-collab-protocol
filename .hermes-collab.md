# Hermes Collab Protocol

This repo contains the Hermes Collab Protocol — enabling multi-device AI agent collaboration across teams.

## Setup

1. Clone this repo
2. Run `./install.sh` or manually copy `project-collab.py` to `~/.hermes/scripts/`
3. Copy `SKILL.md` to `~/.hermes/skills/hermes-collab/`
4. Set `~/.config/device-label` with your device name
5. Run `project-collab.py init` in any project repo

## Files

| File | Purpose |
|------|---------|
| `project-collab.py` | Orchestration script (init, claim, work, sync, report) |
| `SKILL.md` | Hermes skill definition — auto-detects `.hermes-collab.md` in repos |
| `reference-manifest.md` | Template for `.hermes-collab.md` |
| `install.sh` | One-command setup for new devices |
| `README.md` | Full documentation |
